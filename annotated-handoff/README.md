# Native Japanese MVP Annotated UI Handoff

基于已确认的小样和编辑体验制作。统一入口：`index.html`。

## 查看与分享

- 双击 index.html，使用浏览器打开；也可通过本地预览服务器打开。
- 默认查看模式，顶部选择页面或用上一/下一视图浏览。
- 共覆盖 29 个 App 页面；包含弹窗、菜单、会员和收藏状态及长页面下方内容，共 57 个阅读视图、176 条标注。
- 截图已嵌入 HTML，分享 index.html 一个文件即可，不依赖图片目录或网络。

## 编辑

点击「编辑模式」，选中标注后修改编号、名称、说明。拖动标注框移动整条标注；拖文字或编号可独立调整。按住 Shift 拖框只移动框。拖引线或其三个圆点可调整引线。支持新增、复制、删除。

修改自动保存在当前浏览器。点击「下载可编辑 HTML」可保存全部页面的最新标注。下载文件默认仍为查看模式，并保留完整编辑能力。浏览器中的修改不会自动同步给其他人；分享时请使用最新下载文件。

## 内容口径

只以当前 App 的真实截图、现有代码和已有审计资料为依据。重复控件按功能合并，不把交互记录逐条转成标注。页面跳转标明目标；对模拟播放、录音、开通等保留必要的简短说明。

录音与评价弹窗的遮挡截图已从交付浏览列表移除，原截图与旧 QA 图仅作历史备份保留。未修复或改动 App。

收藏课程与收藏播客相邻；会员中心紧随开通成功页。会员中心为现有 membership 页的已开通状态，暂保留待用户确认。

2026-09-17 本轮文案按用户确认的正式功能要求更新，仅修改设计交付说明，未实现对应 App 功能。

## 文件

- index.html：唯一交付入口，内嵌全部截图。
- screens/：真实 App 截图备份。
- preview.png：首页交付预览。
- spec.json、captures.json：制作与坐标依据，不在交付主界面显示。
- capture.cjs、build.py、qa.cjs：本机制作与检查脚本；从项目根目录运行。
- qa/：各阅读视图的视觉校验图。

原 annotated-prototype 与 docs 保持原样，不需要运行旧审计脚本。
